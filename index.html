Raccourcis iPhone

Tes valeurs

Ces trois valeurs servent dans le raccourci Kairos. Le jeton est personnel : il permet seulement d'ajouter des minutes à ton compte.

Adresse (URL)
En-tête apikey
Jeton (p_token)

Guides

① Créer le raccourci « Kairos »
  1. App Raccourcis → onglet Raccourcis → +. Touche le nom en haut → Renommer → Kairos.
  2. Ajoute Obtenir le contenu de l'URL. Remplace « URL » par l'adresse copiée plus haut, puis touche › pour déplier :
    • Méthode : POST
    • En-têtes → Ajouter un nouvel en-tête : clé apikey, texte = la clé copiée
    • Corps de requête : JSON → Ajouter un nouveau champ → Texte : clé p_token, valeur = ton jeton
    • Ajouter un nouveau champ → Texte : clé p_app. Pour la valeur, touche le champ puis choisis Entrée du raccourci dans la barre au-dessus du clavier.
  3. Un bloc Recevoir … de … apparaît en haut : choisis Texte (la source peut rester « Nulle part »). Pour « S'il n'y a aucune entrée », choisis Demander : tu pourras tester en tapant insta open.
  4. Ajoute Obtenir la valeur du dictionnaire : Valeur pour la clé message dans Contenu de l'URL.
  5. Ajoute Si : Valeur du dictionnaire possède n'importe quelle valeur. Dedans : Afficher la notification avec la Valeur du dictionnaire.
  6. Après Terminer si, ajoute Obtenir la valeur du dictionnaire : clé ouvrir, puis touche l'entrée et choisis Contenu de l'URL.
  7. Ajoute un second Si : cette nouvelle Valeur du dictionnaire possède n'importe quelle valeur. Dedans : Ouvrir l'app → Manga Pin.
  8. Test : touche ▶, tape insta close. Rien ne doit s'afficher ni s'ouvrir, et « Dernier signal » passe à « à l'instant ». Si une notification « Jeton Kairos inconnu » apparaît, recopie ton jeton.
② Créer les 4 automatisations
  1. Onglet Automatisation → + → App → Choisir → Instagram. Coche seulement Est ouverte, choisis Exécuter immédiatement et désactive Avertir lors de l'exécution → Suivant.
  2. Nouvelle automatisation vide → ajoute Texte : insta open → ajoute Exécuter le raccourci → choisis Kairos. L'action doit afficher « Exécuter Kairos avec Texte ». Déplie-la (›) et désactive Afficher pendant l'exécution.
  3. Recommence trois fois en changeant l'app, la case et le texte :
    • Instagram, Est fermée → insta close
    • Manga Pin, Est ouverte → lecture open
    • Manga Pin, Est fermée → lecture close
  4. Teste : ouvre Insta puis ferme-le, et reviens sur Kairos. Sous le bouton « Lire maintenant », « Dernier signal » doit indiquer « à l'instant ».
③ Bouton « Lire maintenant » (facultatif)
  1. Crée un raccourci nommé Kairos Lire avec une seule action : Ouvrir l'app → Manga Pin.
  2. Le gros bouton de l'onglet « Ce soir » le lance.
④ Apple Pay → Argent
  1. App Raccourcis → onglet Automatisation → + → Wallet (« Transaction » sur les anciens iOS). Choisis ta ou tes cartes, puis Exécuter immédiatement → Suivant → Nouvelle automatisation vide.
  2. Ajoute Obtenir le contenu de l'URL avec cette adresse :
    Déplie avec › : Méthode POST ; En-têtes : apikey = la même clé que pour le raccourci Kairos ; Corps JSON avec trois champs Texte :
    • p_token = ton jeton (le même que pour le raccourci Kairos)
    • p_amount = touche le champ, choisis Entrée du raccourci, puis touche la bulle et choisis Montant
    • p_merchant = Entrée du raccourci → Commerçant
  3. Pour les alertes de budget : ajoute Obtenir la valeur du dictionnaire message dans Contenu de l'URL, puis Si Valeur du dictionnaire possède n'importe quelle valeur → dedans, Afficher la notification avec la Valeur du dictionnaire. Sans ce Si, chaque paiement afficherait une notification vide.
  4. Si rien n'arrive : Réglages iPhone → Apps → Wallet, active Données cellulaires.
  5. Les paiements par carte physique ou en ligne ne passent pas par là : ajoute-les à la main dans l'onglet Argent, ça prend 5 secondes.
⑤ Garmin → Nuits
  1. Garmin Connect → Plus (≡) → Paramètres → Applications connectées → Apple Santé → active Sommeil (et autorise dans la fenêtre Santé). Synchronise ta montre, puis vérifie dans Santé → Parcourir → Sommeil que ta dernière nuit apparaît.
  2. App Raccourcis → + → renomme-le Kairos Nuit. Ajoute Rechercher des échantillons de santé : touche Type → Analyse du sommeil. Ajoute un filtre Date de début est dans les derniers 7 jours. Trier par Date de début, ordre Croissant, Limite désactivée.
  3. Ajoute Répéter avec chaque élément (sur les échantillons). Dedans, ajoute Texte et compose : Élément répété → touche la bulle → Date de début, tape |, Élément répété → Date de fin, tape |, Élément répété → Valeur.
    Touche chaque bulle de date → Format de date : ISO 8601 et active Inclure l'heure.
  4. Après Fin de la répétition, ajoute Combiner le texte : Résultats de la répétition avec Nouvelle ligne.
  5. Ajoute Obtenir le contenu de l'URL avec cette adresse :
    Déplie avec › : Méthode POST ; En-têtes : apikey = la même clé que pour le raccourci Kairos ; Corps JSON : p_token = ton jeton, p_data = Texte combiné.
  6. Ajoute Obtenir la valeur du dictionnaire message dans Contenu de l'URL, puis Si Valeur du dictionnaire possède n'importe quelle valeur → dedans, Afficher la notification avec cette valeur.
  7. Dans le corps JSON, ajoute un champ Booléen : p_quiet = Vrai. Kairos ne t'enverra un message que s'il y a une nouvelle nuit.
  8. Onglet Automatisation → + → App → choisis l'app que tu ouvres en premier le matin (Instagram, Discord…) → Est ouverte, Exécuter immédiatement, désactive M'avertir lors de l'exécution → Exécuter le raccourci → Kairos Nuit (désactive Afficher pendant l'exécution).
    Pourquoi pas une heure fixe ? iOS rend les données Santé illisibles tant que l'iPhone est verrouillé : une automatisation « 11:00 » qui tourne dans ta poche ne trouve rien. À l'ouverture d'une app, l'iPhone est forcément déverrouillé.
