Raccourcis iPhone

Ces trois valeurs servent dans le raccourci Kairos. Le jeton est personnel : il permet seulement d'ajouter des minutes à ton compte.

Adresse (URL)
En-tête apikey
Jeton (p_token)
① Créer le raccourci « Kairos »
  1. App Raccourcis → onglet Raccourcis → +. Nomme-le exactement Kairos.
  2. Ajoute Diviser le texte : Entrée du raccourci par Espaces. (S'il demande quoi recevoir, choisis Texte.)
  3. Ajoute Obtenir l'élément de la liste : Premier élément de Texte divisé, puis Définir la variable app.
  4. Ajoute Obtenir l'élément de la liste : Dernier élément de Texte divisé, puis Définir la variable event.
  5. Ajoute Obtenir le contenu de l'URL avec l'adresse copiée plus haut. Touche la flèche pour déplier :
    • Méthode : POST
    • En-têtes : clé apikey, valeur = la clé copiée
    • Corps de requête : JSON, trois champs Texte : p_token = ton jeton, p_app = variable app, p_event = variable event
  6. Ajoute Obtenir la valeur du dictionnaire : valeur pour action dans Contenu de l'URL, puis Définir la variable action.
  7. Ajoute Si : action n'est pas none. Dedans : Obtenir la valeur du dictionnaire message dans Contenu de l'URL, puis Afficher la notification avec cette valeur.
  8. Ajoute un second Si : action est redirect. Dedans : Ouvrir l'app → Manga Pin.
② Créer les 4 automatisations
  1. Onglet Automatisation → + → App → choisis Instagram, coche seulement Est ouverte, choisis Exécuter immédiatement et désactive Avertir lors de l'exécution → Suivant.
  2. Nouvelle automatisation vide → ajoute Texte : insta open → ajoute Exécuter le raccourci : Kairos (son entrée doit être le Texte).
  3. Recommence trois fois en changeant l'app, la case et le texte :
    • Instagram, Est fermée → insta close
    • Manga Pin, Est ouverte → lecture open
    • Manga Pin, Est fermée → lecture close
  4. Teste : ouvre Insta puis ferme-le, et reviens sur Kairos. Sous le bouton « Lire maintenant », « Dernier signal » doit indiquer « à l'instant ».
③ Bouton « Lire maintenant » (facultatif)
  1. Crée un raccourci nommé Kairos Lire avec une seule action : Ouvrir l'app → Manga Pin.
  2. Le gros bouton de l'onglet « Ce soir » le lance.
